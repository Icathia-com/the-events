# Design reference: The Events

These are the approved screens from the design canvas "Volunteer Network app" (27 to 28 Oct 2026), one file per screen. Use them as the visual reference for the build: layout, spacing, colours, wording, states.

They are prototypes, not production code. They use template placeholders ({{ }}), <sc-for> and <sc-if> tags, and localStorage sample data. Rebuild them as real pages per BACKEND-BRIEF.md; do not copy their code structure. All names, organisations and numbers in them are invented sample data.

Main screens: Home, Discover, Event-Create, Event-Detail, Manage-Event, Events-Map (Phase 3), Profile, Organisations, Organisation, Notifications.
Manage sub-screens: Volunteers, Check-In, Hosts, Access, Vouchers, Questions, Blasts (Announcements), Insights, Invite, Event-Chat.
Hours: Check-Out, Claim-Hours, Hours-Record, Letter-Requests.
